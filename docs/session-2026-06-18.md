## ข้อเสนอแนะสำหรับอนาคต

### เร่งด่วน (ควรทำก่อน production)

1. **เก็บ agent log ลงไฟล์ JSONL** — ตอนนี้เก็บใน memory 200 entries เท่านั้น restart server หาย. แนะนำเขียนลง `outputs/agent-logs/YYYY-MM-DD.jsonl` parallel กับ in-memory store
2. **ลบ orphan files** — [manager.md](../prompts/manager.md), [report.md](../prompts/report.md), [reportAgent.ts](../src/agents/reportAgent.ts), `managerReview()` ใน [managerAgent.ts](../src/agents/managerAgent.ts) — ไฟล์ที่ไม่มีคนเรียก แต่ยังอยู่ทำให้คนสับสน
3. **เพิ่ม Cert handling** — ตอนนี้ใช้ demo fallback แก้ปัญหา cert error ชั่วคราว แต่ production ควรหา root CA bundle (NODE_EXTRA_CA_CERTS) ให้ตรงกับ environment
4. **Test coverage prompts ใหม่** — prompts ที่เขียนใหม่ยังไม่ได้รันจริง ควรรัน `auto:once` แล้วเช็ค output ทุก agent ผ่าน schema validation

### กลาง (เพิ่ม value ทันที)

5. **CEO Directives Phase B** — wire `focus_categories` เข้า [productService](../src/services/productService.ts) และ promotion ranking. ตอนนี้ Phase A ทำแล้ว (prompts ฟัง CEO) แต่ business logic ใน TypeScript ยัง ignore field นี้
6. **Persistent notifications** — ตอนนี้ notification รวมจาก dashboard alerts ที่ refresh ทุก 5s. ถ้าเจ้าของร้านปิดเครื่องไป 1 ชม. กลับมา จะไม่เห็นว่าเกิดอะไรระหว่างนั้น. ควรเพิ่ม notification table ใน Sheets เก็บ event log
7. **Mobile responsive ของหน้าใหม่** — AI Conversations + Theme toggle ยังไม่ได้ทดสอบบนจอเล็ก
8. **Prompt versioning** — prompts ที่เขียนใหม่ตอนนี้ overwrite ของเก่า ถ้า output คุณภาพแย่ลง rollback ยาก. ควรใช้ git tag หรือเก็บ snapshot ใน [prompts/archive/](../prompts/) เวลาแก้

### ยาว (improvement / nice-to-have)

9. **CEO Command Panel (Phase C)** — ให้เจ้าของร้านพิมพ์คำสั่งสด ("ดัน SKU-X เป็น hero") + เก็บใน Sheets table ใหม่ → workflow ดูก่อนรัน
10. **Cost tracking** — agent log ตอนนี้ไม่เก็บ token count. เพิ่ม column นี้จะดู cost per workflow ได้
11. **Diff viewer ใน prompts** — เปลี่ยน prompt แล้วรัน ก่อน-หลัง output ต่างกันยังไง? เพิ่มหน้าเทียบ
12. **A/B test framework** — รันคู่ Gemini vs Claude บน prompt เดียว เทียบผล
13. **Sentry / error tracking** — ถ้า workflow fail จริงในระบบจริง ตอนนี้รู้แค่จาก notification
14. **Accessibility audit** — keyboard navigation, screen reader support ยังไม่ได้ตรวจครบทุกหน้า
15. **Performance** — Dashboard polling ทุก 5s + AgentLogs polling 5s + NotificationBell 15s = ค่อนข้างเยอะ. พิจารณา WebSocket หรือ SSE แทน

16. **String-as-key** ในหลายที่ (`watchouts.map(item => key={item})`) — ถ้าข้อมูล duplicate จะหาย แต่ในทางปฏิบัติ backend dedupe อยู่แล้ว — ทำความสะอาดถ้ามีเวลา
17. **Inline styles** ใน [NotificationBell.tsx:315](../web-src/NotificationBell.tsx#L315) (`style={{ visibility: "hidden" }}`) ควรย้ายเข้า CSS class
18. **DashboardData type ซ้ำ** — type นี้นิยามใน App.tsx และ OverviewPage.tsx แยกกัน ไม่ sync — ควรย้ายไป `web-src/types.ts` รวม
